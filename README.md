# 🧮 Python Calculator

## Description

A simple calculator application built using Python that performs basic arithmetic operations like addition, subtraction, multiplication, and division. The program uses a menu-driven approach and runs through the command line.

## Features

* Addition of two numbers
* Subtraction of two numbers
* Multiplication of two numbers
* Division of two numbers
* Division by zero error handling
* Simple and user-friendly interface

## Technologies Used

* Python 3

## Project Structure

Calculator/

## How to Run

1. Clone the repository:

```bash
git clone https://github.com/your-username/calculator.git
```

2. Open the project folder:

```bash
cd calculator
```

3. Run the Python file:

```bash
python calculator.py
```
